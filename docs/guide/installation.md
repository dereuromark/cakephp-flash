# Installation

From your application's root directory:

```sh
composer require dereuromark/cakephp-flash
bin/cake plugin load Flash
```

Composer checks the supported PHP and CakePHP versions. This branch targets CakePHP 5; see [composer.json](https://github.com/dereuromark/cakephp-flash/blob/master/composer.json) for the current constraints.

Continue with [Getting started](./getting-started.md) to load the component and helper and create the templates. The plugin does not need a database table or plugin routes.
